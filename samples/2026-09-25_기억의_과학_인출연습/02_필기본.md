# 02 필기본 — 기억의 과학: 인출 연습

> 사용법: ① 필기 칸을 종이로 가린다 → ② 왼쪽 단서 질문에 소리 내어 답한다 → ③ 펼쳐서 확인한다 → ④ 막힌 질문에 ✔ 표시

## 1. 오늘의 질문 · 망각곡선 [00:00–01:01]

::: cornell
::: cue
- 이 강의가 답하려는 질문을 가리고 말할 수 있나?
- 망각곡선의 모양을 손으로 그리며 설명할 수 있나?
- 망각이 '게으름 탓'이 아닌 이유는?
:::
::: note
**?** 여러 번 다시 읽었는데 왜 시험장에선 기억이 안 날까 [00:10]

**망각곡선** (에빙하우스) = 새로 배운 내용이 시간에 따라 얼마나 빨리 잊히나 → 그래프 [00:22]

- 배운 직후: 기억 ↓↓ (가장 빠르게) [00:39]
- 시간 ↑ → 떨어지는 속도 ↓
- ∴ 망각 ≠ 게으름 → 뇌의 원래 작동 방식 [00:50]
:::
:::

::: summary
배운 내용은 직후에 가장 빨리 잊히고 이후 천천히 잊힌다. 망각은 정상 작동이므로, 문제는 "잊는다"가 아니라 "잊는 것에 어떻게 대처하느냐"다.
:::

## 2. 다시 읽기와 유창성 착각 [01:01–02:06]

::: cornell
::: cue
- "더 많이 읽으면 된다"가 왜 착각인지 인과로 설명할 수 있나?
- 유창성 착각을 가리고 정의할 수 있나?
- '알아보는 능력'과 '꺼내는 능력'을 구별하는 기준은?
- 다시 읽기만 한 학생이 시험장에서 막히는 과정을 단계별로?
:::
::: note
학생 생각: 잊음 → ∴ 더 많이 읽자 [01:01]
★ "이게 바로 착각. 정말 중요" [01:11]

다시 읽기 → 눈에 **익숙** → "안다"고 느낌 [01:11]–[01:26]
= **유창성 착각** [01:26]

| 익숙한 느낌 | ≠ | 스스로 꺼내기 |
|---|---|---|
| 알아보는 능력 | | 꺼내는 능력 ← 시험이 요구 |

[01:37]–[01:47]

∴ 공부할 땐 "다 안다" → 시험장에선 막힘 [01:47]
:::
:::

::: summary
다시 읽기는 익숙함을 키워 안다고 착각하게 만든다(유창성 착각). 하지만 시험은 알아보기가 아니라 꺼내기를 요구하므로, 다시 읽기만 한 학생은 시험장에서 막힌다.
:::

## 3. 인출 연습과 숲길 비유 [02:06–03:11]

::: cornell
::: cue
- 인출 연습을 가리고 정의할 수 있나?
- 인출 연습의 예를 세 가지 댈 수 있나?
- 꺼내기가 왜 기억을 강화하는지 숲길 비유로 설명하면?
- 읽기와 인출의 차이를 비유 하나로?
:::
::: note
**인출 연습** = 책 덮고 → 기억에서 스스로 꺼내 보기 [02:06]

예) 백지 쓰기 · 스스로 문제 풀기 · 친구에게 설명 [02:25]

★ 꺼내려 **애쓰는 과정 자체** → 기억으로 가는 길 튼튼 [02:36]

비유: 숲길 [02:45]
- 한 번 지나간 길 → 흐릿
- 여러 번 걸은 길 → 뚜렷
- 읽기 = 남이 낸 길 구경 / 인출 = 내 발로 걷기 [03:01]
:::
:::

::: summary
인출 연습은 책을 덮고 스스로 꺼내 보는 공부다. 꺼내려고 애쓰는 과정이 기억으로 가는 길을 튼튼하게 만든다 — 길은 구경이 아니라 걸어야 생긴다.
:::

## 4. 실험: 네 번 읽기 vs 세 번 떠올리기 [03:11–03:56]

::: cornell
::: cue
- 실험 설계(두 집단)를 가리고 말할 수 있나?
- '직후'와 '일주일 뒤' 결과가 왜 뒤집혔나?
- 이 실험이 유창성 착각의 증거가 되는 이유는?
:::
::: note
실험 [03:11]
- 집단 A: 글 **4회 읽기**
- 집단 B: **1회 읽기 + 3회 떠올리기**

| 시점 | 더 잘한 쪽 |
|---|---|
| 공부 직후 (느낌) | A가 "더 잘 기억한다"고 **느낌** [03:27] |
| 일주일 뒤 (시험) | B가 훨씬 더 많이 기억 [03:35] |

∴ 공부할 때의 **느낌 ≠ 실제 기억** [03:45]
:::
:::

::: summary
읽기만 한 집단은 더 잘 안다고 느꼈지만, 일주일 뒤엔 떠올리기 연습을 한 집단이 훨씬 더 많이 기억했다. 느낌은 실제 기억을 보장하지 않는다.
:::

## 5. 간격 두기와 바람직한 어려움 [03:56–05:07]

::: cornell
::: cue
- 간격 두기가 인출을 '어렵게' 만드는 이유는?
- 어려운데 왜 오히려 기억이 강해지나?
- "어렵기만 하면 좋다"가 틀린 이유를 조건과 함께?
- 간격이 너무 길 때 무슨 일이 일어나나?
:::
::: note
**간격 두기** = 몰아서 ✗ → 시간 간격 두고 나눠 복습 [04:05]

왜? [04:17]
간격 → 조금 잊음 → 꺼내기 더 어려움 → (적당히 어려운 인출) → 기억 ↑↑ [04:30]
= **바람직한 어려움** [04:30]

⚠ 오해 주의 [04:43]
- 어렵기만 하면 ✗
- 너무 많이 잊음 → 전혀 못 꺼냄 → 인출 자체 ✗ [04:53]
- ∴ 간격 너무 길어도 ✗
:::
:::

::: summary
간격을 두면 조금 잊은 상태에서 꺼내야 하므로 인출이 적당히 어려워지고, 그 어려움이 기억을 더 강하게 만든다. 단 너무 잊으면 인출이 아예 일어나지 않으므로 간격은 '적당히'.
:::

## 6. 정리와 숙제 [05:07–05:53]

::: cornell
::: cue
- 강사의 정리 네 문장을 순서대로 말할 수 있나?
- 오늘의 숙제는 무엇이고, 그 자체가 어떤 공부법인가?
:::
::: note
정리 [05:07]–[05:22]
1. 망각 → 자연스러움
2. 다시 읽기 → 익숙함만 → 안다는 착각
3. 인출 연습 → 꺼내는 과정에서 기억 강화
4. 간격 → 적당히 어려운 인출 → 효과 ↑

숙제: 책 덮고 → 오늘 개념 3가지 백지에 쓰기 [05:37]
(= 인출 연습 그 자체)
:::
:::

::: summary
망각은 자연스럽다 → 다시 읽기는 착각만 준다 → 꺼내야 기억이 강해진다 → 간격을 두면 더 강해진다.
:::

## 전체 요약
::: summary
망각은 정상이다(원인). 그런데 다시 읽기로 대처하면 익숙함 때문에 안다고 착각할 뿐, 시험이 요구하는 꺼내는 능력은 길러지지 않는다(잘못된 과정). 그러므로 책을 덮고 스스로 꺼내는 인출 연습을, 조금 잊을 만한 적당한 간격을 두고 해야 기억이 오래 간다(올바른 과정 → 결과).
:::

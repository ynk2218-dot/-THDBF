## 5. 인과 사슬 (강의의 뼈대)
- 사슬 A (문제): 다시 읽기 → 글이 익숙해짐 → 안다고 느낌(유창성 착각) → 꺼내는 능력은 훈련되지 않음 → 꺼내기를 요구하는 시험에서 막힘 [01:11, 01:26, 01:37, 01:47]
- 사슬 B (해결): 인출 연습 → 꺼내려고 애씀 → 기억으로 가는 길이 튼튼해짐 → 일주일 뒤에도 더 많이 기억 [02:06, 02:36, 03:35]
- 사슬 C (강화와 한계): 간격 두기 → 조금 잊은 상태 → 적당히 어려운 인출(바람직한 어려움) → 기억 더 강화 / 간격 과다 → 전혀 꺼낼 수 없음 → 인출 불발 [04:17, 04:30, 04:53]

# 03_필사본 작성 가이드

**목적: 재구성.** 손으로 옮겨 쓰며 강사의 논리 흐름을 몸에 새기고, 이어서 내 말로 바꿔 써 본다.
"베끼기 → 이해 → 재표현"의 3단계.

## 문장 고르는 기준 (config: min_sentences~max_sentences 개)
우선순위:
1. 정의·원리를 한 문장에 담은 문장
2. 인과를 말하는 문장 ("~ 때문에", "그래서", "~하면 ~된다")
3. 강사가 강조·반복한 문장 (analysis 6번)
4. 강의의 결론·핵심 질문에 답하는 문장
- 강의 흐름 순서대로 배치. 한 개념에 몰리지 않게 목차 전 구간에서 고르게.
- **발화를 정제**하되 의미·어휘는 강사 것을 유지 (말버릇·중복만 제거, 새 단어 추가 금지).

## 형식

```markdown
# 03 필사본 — {강의 제목}

> 사용법: ① 원문을 천천히 옮겨 쓴다 → ② '왜 핵심인가'를 읽는다 → ③ 원문을 가리고 내 말로 바꿔 쓴다 → ④ 원문과 비교해 빠진 논리 연결어를 찾는다

::: item 01 · [01:12]
> {정제한 강사 발화}

✍ **따라 쓰기**

______________________________

______________________________

💡 **왜 핵심인가** — {이 문장이 강의 구조에서 하는 역할 한 줄: 예) "이후 모든 설명의 전제가 되는 정의"}

🔁 **내 말로 바꿔 쓰기**

______________________________

______________________________
:::
```

## 영어 강의일 때 (원문 아래 두 줄 추가)
```markdown
> The price of a good rises / when demand exceeds supply, / because buyers compete / for a limited quantity.

**끊어읽기** — The price of a good rises / when demand exceeds supply, / because buyers compete / for a limited quantity.
**해석** — 수요가 공급을 넘으면 재화의 가격이 오른다. 구매자들이 한정된 양을 두고 경쟁하기 때문이다.
```
- 끊어읽기는 의미 단위(주어부 / 동사부 / 절 / 전치사구)로. 사선 앞뒤 공백 하나.
- 해석은 직역에 가깝게, 인과 연결어(because, so, therefore)를 살린다.

## 맨 끝

```markdown
## 복기

```

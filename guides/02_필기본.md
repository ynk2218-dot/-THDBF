# 02_필기본 작성 가이드 (코넬 노트)

**목적: 재구성.** 강의를 판서처럼 압축한 노트. 복습 때 필기 칸을 가리고 단서 질문만 보며 설명해 보는 용도.

## 형식
목차의 구간(또는 개념 묶음)마다 코넬 블록 하나.

```markdown
# 02 필기본 — {강의 제목}

> 사용법: ① 필기 칸을 종이로 가린다 → ② 왼쪽 단서 질문에 소리 내어 답한다 → ③ 펼쳐서 확인한다 → ④ 막힌 질문에 ✔ 표시

## 1. {소주제} [00:00–02:15]

::: cornell
::: cue
- 이걸 가리고 ○○가 왜 생기는지 설명할 수 있나?
- ○○와 △△의 차이를 한 문장으로?
- 강사가 든 예시로 원리를 다시 말해 보면?
:::
::: note
**○○** = … [01:12]

- 원인: 가격↑ → 대체재 매력↑ → 수요량↓
- ∴ …
- ≠ △△ (△△는 …)
- 예) 강사 예시: … [01:40]
- ★ 강조: "…" [02:05]
:::
:::

::: summary
이 구간의 핵심을 **세 줄 이내 인과 문장**으로.
:::
```

## 작성 요령
- **필기 칸**: 키워드·기호·화살표 중심. 완결된 문장은 최소화(정의 한 줄 정도만).
  자주 쓰는 기호: `→`(그래서/원인→결과) `←`(왜냐하면) `∴`(결론) `∵`(이유) `≠`(구별) `≈`(비슷) `↑↓`(증감) `★`(강조) `?`(강사가 던진 질문) `vs`
- 들여쓰기로 위계를 표현. 판서하듯 짧게.
- 각 핵심 줄 끝에 근거 ts.
- **단서 칸**: 사실 확인("정의는?")보다 **설명 요구형** 질문 위주.
  - "이걸 가리고 ~를 설명할 수 있나?"
  - "왜 ~가 ~로 이어지나?"
  - "~와 ~를 구별하는 기준은?"
  - "강사의 예시 대신 다른 예를 들면?"
  한 블록에 2~4개.
- **요약 칸**: 이 구간이 강의 전체에서 하는 역할이 드러나게. 세 줄 이내.
- 필기 칸 안에 표·코드블록도 가능. 단, 너무 길면 블록을 나눈다(한 블록 ≈ A4 반 페이지).
- 맨 끝에 전체 요약 한 블록:

```markdown
## 전체 요약
::: summary
강의 전체를 원인 → 과정 → 결과 한 문단으로.
:::
```

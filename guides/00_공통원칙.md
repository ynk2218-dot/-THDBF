# 공통 원칙 — 모든 자료에 적용

## 이 도구의 교육관
학습자는 개별 사실보다 **원인 → 과정 → 결과**의 구조로 이해할 때 납득한다.
따라서 모든 자료는 "외우게" 하기보다 **이해하고 → 검증하고 → 스스로 써먹게** 설계한다.

| 단계 | 담당 자료 | 학습자가 하는 일 |
|---|---|---|
| 이해 | 01 정리본 | 개념이 *왜* 필요하고 *어떻게* 작동하는지 구조로 파악 |
| 재구성 | 02 필기본 · 03 필사본 | 강의를 자기 기호·자기 말로 다시 짬 |
| 인출·검증 | 04 워크북 | 보지 않고 꺼내 보며 어디서 막히는지 확인 |
| 적용·진단 | 05 문제지 | 새 상황에 써 보고, 틀린 원인을 태그로 데이터화 |

## 사실성 규칙 (가장 중요)
1. **강의에 없는 내용을 지어내지 않는다.** 근거는 `_source/transcript_raw.md` 와 `analysis.md` 뿐이다.
2. 이해를 위해 꼭 필요한 보충(용어 정의, 전제 지식, 반례 등)은 쓰되 문장 앞에 **`[보충]`** 을 붙인다.
   - `[보충]` 문장에는 타임스탬프를 달지 않는다(강의 근거가 없으므로).
   - 강의와 충돌할 수 있는 보충은 쓰지 않는다.
3. 핵심 주장·정의·인과 설명에는 **근거 타임스탬프** `[mm:ss]` (1시간 이상이면 `[hh:mm:ss]`)를 단다.
   - 타임스탬프는 반드시 `transcript_raw.md` 에 실제로 있는 블록 시작 시각(또는 그 사이)을 쓴다. 추측 금지.
   - 구간은 `[03:10–05:42]` 형식.
4. 음성 인식 오류로 보이는 용어는 문맥으로 교정하되, `analysis.md` 10번 항목에 교정 내역을 남긴다.
5. 강사의 예시·비유는 강사 것을 우선 쓴다. 새 예시가 필요하면 `[보충]` 표시.
6. 교재(`--material`)를 함께 받았다면 교재도 근거가 된다. 교재에서 가져온 내용에는 `[교재 p.N]` 을 단다.
   사용 범위와 우선순위는 `guides/00_교재.md` 를 따른다.

## 일관성 규칙
- 개념 이름·ID(C1, C2 …)·인과 관계는 **analysis.md 를 단일 기준**으로 삼는다.
  정리본에서 A→B 라 했으면 문제·해설에서도 A→B 여야 한다.
- 5종 자료 모두 같은 용어 표기를 쓴다(원어 병기는 처음 한 번: `기회비용(opportunity cost)`).

## 난이도 (--level)
- **기본**: 강의 범위 안에서 정의·원리·예시를 확실히. 적용 문제는 강의 예시와 구조가 비슷한 상황.
- **심화**: 개념 간 비교·경계 조건·"만약 ~라면?" 변형·강의 논리의 한계 탐색까지. 한계·반례는 대부분 `[보충]`.

## 언어
- 자료는 `meta.json` 의 `output_language`(기본 ko)로 쓴다.
- 영어 강의: 필사본의 원문은 영어 그대로 + 끊어읽기 + 해석. 핵심 용어는 `한국어(English)` 병기.

## Markdown 확장 문법 (PDF 변환기가 인식)
```
::: 이름 [라벨]      → 상자. 이름: card, box, tip, warn, write, item, q, cornell, cue, note, summary, head, answers
…내용…
:::                 → 닫기 (중첩 가능)

______________      → (한 줄 전체가 밑줄 5개 이상) 손으로 쓰는 줄 한 줄
(______)            → 문장 속 빈칸
- [ ] 항목           → 체크박스
[보충] [교재 p.12] [기본] [응용] [심화] [개념 미이해] [적용 실패] [용어 혼동] [부주의] → 색 배지로 표시됨
```mermaid           → 관계도 그림
```
- 쓰기 줄(`______`)은 목록·표 **밖**에, 앞뒤 빈 줄을 두고 쓴다.
- 가로 구분선은 `---` 만 쓴다(밑줄 줄과 헷갈리지 않게).

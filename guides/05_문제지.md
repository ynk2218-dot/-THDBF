# 05_문제지 + 05_정답해설 작성 가이드

**목적: 적용·진단.** 문제는 '맞았나'보다 **'왜 틀렸나'를 데이터로 남기는** 도구다.
문항 수·유형·난이도 비율은 `meta.json` → `config.materials.문제지` 를 정확히 따른다.

## 출제 원칙
- 난이도 정의
  - **[기본]** 강의에서 직접 말한 정의·인과를 확인 (재인)
  - **[응용]** 강의 원리를 강의와 다른 예·상황에 적용
  - **[심화]** 여러 개념 결합 / 조건이 바뀌면 결과가 어떻게 달라지는지 / 강의 논리의 전제 검토
- 객관식 오답(매력적 오답)은 **각각 특정 오해를 겨냥**해 만든다. 오답마다 오답 원인 태그가 하나씩 대응해야 한다.
  - [개념 미이해] 원리·인과 방향을 잘못 이해했을 때 고르게 되는 선택지
  - [용어 혼동] 비슷한 용어를 바꿔 넣은 선택지
  - [적용 실패] 원리는 맞지만 새 상황에 잘못 대응시킨 선택지
  - [부주의] 조건어(항상/일부/아닌 것)·부정문을 놓칠 때 고르는 선택지
- 한 개념에 문항이 몰리지 않게. 핵심 개념은 모두 최소 1문항.
- 문항 순서: 기본 → 응용 → 심화 (유형은 섞어도 됨).
- 문제지에는 정답·힌트·타임스탬프를 넣지 않는다.

## 05_정답해설.md 형식

```markdown
# 05 정답·해설 — {강의 제목}

## 빠른 정답
| 1 | 2 | 3 | … |
|---|---|---|---|
| ③ | ① | 대체재 | … |

---

### 1. [기본] 정답 ③
**정답 이유** — 강의에서 "…"라고 설명했다 [04:10]. 원인 → 과정 → 결과로 보면 …
**오답 분석**
- ① ✗ … 가 아니라 … 이다. → [개념 미이해] 인과 방향을 거꾸로 이해 [04:10]
- ② ✗ … → [용어 혼동] ○○와 △△를 바꿈 [02:30]
- ④ ✗ … → [적용 실패] …
- ⑤ ✗ … → [부주의] '항상'이라는 조건어
**다시 볼 곳** — [03:50–04:40], 정리본 C2 카드

### 13. [심화] 서술형
**모범 답안** — …
**채점 기준** (부분 점수)
- ☐ 원인을 제시했다 (1)
- ☐ 과정의 연결 고리를 빠뜨리지 않았다 (1)
- ☐ 결과를 조건과 함께 제시했다 (1)
**틀렸다면 원인 진단**
- 원인은 맞는데 과정이 비었다 → [개념 미이해] (C2의 작동 원리 복습)
- 강의 예시로만 답했다 → [적용 실패]

---

## 오답 기록표 (채점 후 직접 기록)
| 문항 | 내 답 | 오답 원인 태그 (하나에 ✔) | 다음 행동 |
|---|---|---|---|
| | | ☐ 개념 미이해 ☐ 적용 실패 ☐ 용어 혼동 ☐ 부주의 | |

::: tip 태그로 보는 나의 약점
- **개념 미이해**가 많다 → 정리본 '작동 원리' + 필기본 단서 질문으로 돌아가기
- **적용 실패**가 많다 → 워크북 D(적용) 반복, 강의 예시를 다른 상황으로 바꿔 보기
- **용어 혼동**이 많다 → 정리본 개념 카드의 '흔한 오해', 비슷한 용어 비교표 만들기
- **부주의**가 많다 → 문제의 조건어에 동그라미 치는 습관
:::
```

## 작성 요령
- 모든 문항의 해설에 **근거 타임스탬프**. 강의에 근거가 없는 선택지 설명은 [보충].
- 단답형은 허용 가능한 동의어를 해설에 명시.
- 문제지 PDF는 2단으로 인쇄되므로 한 문항은 짧게(서술형 쓰기 줄은 3~5줄).

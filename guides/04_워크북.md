# 04_워크북 작성 가이드 (인출 연습)

**목적: 인출·검증.** 보지 않고 꺼내 보는 연습. 정답을 맞히는 것보다 **어디서 막히는지 발견**하는 것이 목표.
문항 수는 config `materials.워크북` 을 따른다.

## 구성 (순서 고정 — 쉬운 인출 → 어려운 인출)

```markdown
# 04 워크북 — {강의 제목}

> 사용법: 정리본·필기본을 **덮고** 푼다. 모르면 비워 두고 다음으로. 마지막 메타인지 체크가 가장 중요하다.

## A. 빈칸 채우기
핵심 용어뿐 아니라 **인과 연결어**(때문에 / 그래서 / 전제로 / 반대로)도 빈칸으로 만든다.
빈칸이 여러 개인 문장은 인과 구조가 드러나게.

1. 가격이 오르면 (______)의 매력이 커지기 (______) 수요량이 줄어든다. [ts]

## B. 원인 – 결과 연결하기
왼쪽(원인)과 오른쪽(결과)을 선으로 잇기. 순서는 섞는다. 오른쪽에 **함정 1개**(강의 내용과 반대 방향 인과) 포함.

| 원인 | | 결과 |
|---|---|---|
| ① … | ○  ○ | ㉠ … |
| ② … | ○  ○ | ㉡ … |

그다음, 한 쌍을 골라 **"왜 그렇게 이어지는지"** 과정을 한 줄로 쓰기:

______________________________

## C. 백지 설명 — 초등학생에게 설명하듯
주제: {핵심 개념 또는 인과 사슬}
조건: 전문용어 쓰지 않기 / 비유 하나 이상 / "왜냐하면"을 두 번 이상 쓰기

::: write 설명 칸
______________________________

______________________________

______________________________

______________________________
:::

## D. 적용 — 강의에 없는 새 상황
강의 예시와 **다른 분야·상황**에 개념을 적용. 상황은 새로 만든 것이므로 [보충] 없이 쓰되,
적용해야 할 원리는 강의에 있는 것이어야 한다(문항 끝에 사용할 개념 ID를 숨기지 말고 "힌트: C2"로).

1. {새 상황 서술} 이 상황에서 {무엇}이 일어날지 강의의 원리로 예측하고, 그 이유를 원인→과정→결과로 쓰시오.

______________________________

______________________________

## E. 메타인지 체크
| 개념 | 자신감 (1~5) | 어디서 막혔나 (구체적으로: 정의? 이유? 예시? 구별?) |
|---|---|---|
| C1 {개념명} | ① ② ③ ④ ⑤ | |

::: tip 다음 행동
- 자신감 1~2 → 정리본의 해당 개념 카드 + 강의 해당 구간 [ts] 다시 보기
- 자신감 3 → 필기본 단서 질문으로 설명 연습
- 자신감 4~5 → 05 문제지 심화 문항에 도전
:::

::: answers
## 확인용 답 (다 푼 뒤에 보기)
A. 1) 대체재 / 때문에 [ts] …
B. ①-㉡ … (함정: ㉣ — 강의에서는 반대 방향 [ts])
C. 채점 기준: ☐ 인과 순서가 맞다 ☐ 핵심 전제를 빠뜨리지 않았다 ☐ 비유가 원리와 구조가 같다
D. 예시 답안 + 채점 포인트 (원리 적용 여부 중심)
:::
```

## 작성 요령
- 빈칸은 "외운 단어"가 아니라 "이해해야 채울 수 있는 자리"에. 연결어 빈칸을 전체의 1/3 이상.
- 확인용 답은 `::: answers` 안에 둔다(PDF에서 새 페이지로 분리되어 미리 보이지 않음).
- 심화 레벨: D의 상황을 강의 원리 두 개 이상을 **함께** 써야 풀리게.
